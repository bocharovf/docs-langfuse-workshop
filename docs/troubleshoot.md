# Если возникли проблемы

## Проект не запускается

Попробуйте удалить все контейнеры и volume с именем langfuse*.

```
docker compose down

docker volume ls

docker volume rm langfuse-workshop_qdrant_data

docker volume rm ...

...

docker compose up -d
```

Проверьте настройки в `.env`, они должны выглядеть примерно так:

![Пример содержимого .env](/img/env-example.png)

## Агент выдает ошибку при обработке запроса

Убедитесь, что все контейнеры запущены с помощью `docker ps -a`, должно быть так:

![Пример содержимого .env](/img/docker-ps.png)

Убедитесь, что в <https://console.mws.ru/> вы корректно создали сервисный аккаунт и развернули все 4 модели (как описано в разделе Подготовка).

## Агент долго отвечает, а в логах есть `LLM rate limit`

MWS GPT ограничивает число запросов в минуту для каждой модели: у `glm-5-3` лимит 10 запросов в минуту, а один ответ агента - это 3-6 запросов к LLM. Если лимит исчерпан, агент ждет его сброса и повторяет запрос, в логах `cookbook-agent` появляется сообщение `LLM rate limit for glm-5-3, retry in ...s`. Это нормально - просто подождите ответа.

## Сценарий не воспроизводится

Убедитесь, что выставлены корректные флаги в `.env` и изменения сохранены.

Выполните полный перезапуск проекта 

```
docker compose up -d --force-recreate
```
